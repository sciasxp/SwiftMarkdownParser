# Deepen Markdown Document construction

SwiftMarkdownParser will treat Markdown Source to complete Markdown Document as the sole public parsing seam: the fixed Supported Dialect is parsed synchronously and atomically by one concurrency-safe module, while token recognition, block construction, inline resolution, references, source spans, diagnostics, and deterministic resource budgets remain internal implementation. This intentionally source-breaking reset removes the public stage modules, ignored mode flags, asynchronous parsing, partial documents, and wall-clock protection without compatibility shims; consumers customize results by transforming the Markdown Document, and the public AST shape remains unchanged until separately reconsidered. We accept source incompatibility to gain locality, leverage, truthful configuration, deterministic verification, and a stable test surface at the document interface.
